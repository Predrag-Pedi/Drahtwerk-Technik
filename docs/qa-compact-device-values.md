# Kompakte Schutzgerätewerte

Stand: 19.11.2026. Gilt für die Makro-Seitenleiste und die Geräteeinstellungen bereits eingesetzter Schutzgeräte.

## Direkt sichtbare Werte

| Einstellung | Häufige Werte |
| --- | --- |
| LS / FI-LS: Bemessungsstrom | 10, 13, 16, 20, 25, 32, 40, 63 A, soweit angeboten |
| FI: Bemessungsstrom | 25, 40, 63 A |
| Charakteristik | B, C |
| Fehlerstrom | 30, 300 mA |
| Fehlerstrom-Typ | A, F |

Alle weiteren bisher angebotenen Werte stehen pro Feld unter «Weitere anzeigen». «Weniger anzeigen» klappt sie wieder ein. Ein ausgewählter Sonderwert bleibt zusätzlich bei den sichtbaren Werten und erscheint nicht doppelt. Die Gruppierung ist eine Bedienvoreinstellung, keine Änderung des Artikelkatalogs oder seiner Kombinationsprüfung. Nicht belegte Polausführungen bleiben deaktiviert und behalten ihren Hinweis.

Der Öffnungszustand wird pro Gerät/Feld gehalten, auch wenn eine Auswahl weitere Artikelwerte aktualisiert oder der rechte Inspector neu gerendert wird. Er wird nicht in Projekten gespeichert. Eine neu geöffnete Vorlage bzw. ein anderes Gerät startet kompakt. Herstellerbindung bleibt optional und standardmässig ausgeschaltet.
